# Protected resources accepted in disposable environments

Linky now includes origin host credentials, receipt-bound resource access,
explicit replacement/retry and private attachment downloads. A dependency-free
server guard checks current authorization before each GET/HEAD, then streams
private bytes. An integrating host must wrap every route and prevent public
static/cache bypasses. A URL or issued key by itself does not install protection.
